Krypton Player — Player / Queue / Equalizer / Lyrics preview screens

These PNGs are visual review mockups of the Compose screen layouts. They are not screenshots captured from a running APK and may not reflect the latest custom playback-control silhouettes.
The current source uses Futuristic Wing Previous/Next icons, a rounded-pill Play/Pause control, and artwork-derived accent colors.
Album artwork shown in the Now Playing preview is a placeholder; the app loads embedded artwork from the currently playing audio file.

Note: These are earlier cyan-accented layout mockups. The current implementation has since moved to a pure-black / charcoal / neutral-white app theme, with artwork-derived colors limited to the Player/Queue and lockscreen.
